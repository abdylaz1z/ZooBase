# ZooBase 0.2.0

Автономный учёт племенных овец Арашан и Ала-Тоо на Android 8.0+.
Интерфейс на кыргызском (по умолчанию) и русском. Данные хранятся на устройстве в SQLite.

## Что работает

- Профиль хозяйства и владельца, карточки животных с фото, чипом, датами и статусом.
- Поиск на кириллице, фильтры, выдача по 50 животных без ограничения общего списка.
- Родители, три поколения родословной, переходы к потомству; проверка циклов и дат.
- История здоровья, обработки, вакцинации и связанные задачи.
- Случки, ожидаемое ягнение, учёт числа и пола ягнят.
- Органайзер: просрочено, сегодня, ближайшие дни и позже.
- Локальные Android-уведомления около 08:00 (включаются в разделе хозяйства).
- Резервная копия базы и фото в ZIP, восстановление и экспорт стада в CSV.
- Светлая/тёмная тема и сохранение настроек.

## Границы версии

Приложение работает с одним локальным хозяйством. Ввод телефона — контакт владельца,
а не SMS-авторизация. Серверная синхронизация, совместная работа, серверные резервные копии,
приглашения, настоящие права доступа и PDF-паспорта не подключены.
Полный анализ требований и ограничений: [docs/REVIEW.ru.md](docs/REVIEW.ru.md).

## На телефоне

1. Установите APK; при запросе разрешите установку из выбранного приложения.
2. Создайте хозяйство или восстановите ZIP-копию на первом экране.
3. Во вкладке «Овцы» нажмите «+», заполните номер и карточку.
4. В карточке добавляйте медицинские и репродуктивные события; задачи появятся в ленте.
5. Для уведомлений включите «Напоминания утром» в разделе «Хозяйство» и разрешите
   уведомления Android. Энергосбережение может сдвигать время. После принудительной
   остановки Android возобновляет уведомления только после открытия приложения.
6. Регулярно сохраняйте ZIP через системный диалог в доступную вне приложения папку.
   При удалении приложения Android удаляет его внутренние данные. CSV — отчёт;
   для восстановления используйте ZIP. Копии не зашифрованы.

Восстановление заменяет текущую базу. Перед заменой приложение делает внутреннюю копию
`before-restore.zip`. Сначала экспортируйте текущую базу, если хотите сохранить её отдельно.
Системный выбор фото/документов не требует доступа ко всей галерее.

## Разработка и тесты

```sh
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
python -m unittest discover -s tests -v
```

Тесты логики используют временные базы и не меняют пользовательские данные.
В Linux UI-сценарий запускается командой `xvfb-run -a python tests/ui_smoke.py`.
GitHub Actions сохраняет снимки экранов в артефакт `ui-verification`.

## Сборка APK

Сборка Kivy для Android выполняется в Linux. Рабочий workflow: `.github/workflows/build-apk.yml`.
Его можно запустить вручную через Actions → Build APK → Run workflow с нужной веткой.
Используются Python 3.11.17, Kivy 2.3.1, Java 17, Buildozer 1.6.0, python-for-android v2026.05.09, NDK 28c,
Android target API 35 / minimum API 26 и архитектуры arm64-v8a, armeabi-v7a, x86_64.

```sh
pip install buildozer==1.6.0 cython==0.29.37 virtualenv
python scripts/prepare_android.py
NO_SQLITE=1 buildozer -v android debug
```

`NO_SQLITE=1` отключает необязательные C-расширения Peewee, но не SQLite и не хранение данных.
Подготовительный скрипт исправляет известное смешивание pip при сборке нескольких архитектур
в p4a v2026.05.09 (upstream issue #3339); версии нативных библиотек не меняются.
APK находится в `bin/`. Это подписанная отладочная сборка для установки и пилотной проверки;
для массового распространения нужна собственная постоянная release-подпись.
На старую установку с другой подписью Android не установит обновление: сначала сделайте
резервную копию в старом приложении. Не удаляйте старую установку до сохранения данных.

После сборки CI устанавливает APK в Android-эмулятор, отключает сеть, проверяет запуск
и повторный запуск и сохраняет `android-verification` с изображениями, logcat и сведениями о пакете.

## Структура

- `main.py` — жизненный цикл, навигация, экспорт/восстановление.
- `zoobase/models.py` — SQLite-модели и миграция старой базы.
- `zoobase/controllers.py` — проверки и транзакции бизнес-операций.
- `zoobase/backup.py` — снимок SQLite через backup API, перенос фото, CSV.
- `zoobase/android_bridge.py` — системные документы и настройка уведомлений.
- `android_src/` — Java-модули Storage Access Framework и AlarmManager.
- `zoobase/views/` — KivyMD-экраны и оформление.
- `zoobase/i18n.py` — русский и кыргызский тексты.
- `tests/` — регрессионные сценарии и Android smoke test.

Исходный репозиторий не содержит явной лицензии; эта итерация не меняет права на исходный код.
