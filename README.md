# ZooBase

ZooBase — мобильное приложение для учёта сельскохозяйственного хозяйства и племенных овец. Приложение помогает вести карточки животных, фиксировать болезни и вакцинации, планировать задачи, отслеживать репродукцию и хранить данные локально на устройстве без необходимости подключения к интернету.

Главные особенности:
- учёт хозяйства и владельца;
- карточки животных с инвентарным номером, породой, полом, датой рождения, родителями и статусом;
- хранение медицинских записей: вакцинации, обработки, болезни и заметки;
- задачи по датам с напоминаниями и фильтрацией по срокам;
- события репродукции: случка и ягнение;
- поиск по кличке, номеру, чипу;
- локальное хранение данных в SQLite;
- интерфейс на русском и кыргызском языках;
- тёмная тема и поддержка фото животных.

## Требования

- Python 3.10+ (рекомендуется 3.11/3.12)
- pip
- на Android: Android SDK/NDK, настроенный через Buildozer

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/abdylaz1z/ZooBase.git
cd ZooBase
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск приложения

```bash
python main.py
```

После запуска приложение создаст локальную SQLite-базу данных в пользовательской директории устройства и начнёт работу с возможностью регистрации хозяйства.

## Сборка для Android

В проекте уже есть файл `buildozer.spec`.

Для сборки Android с помощью Buildozer:

```bash
pip install buildozer
buildozer android debug
```

Или для запуска на подключённом устройстве/эмуляторе:

```bash
buildozer android debug deploy run
```

> Для сборки Android может потребоваться настройка SDK/NDK, Java и необходимых системных пакетов, указанных в документации Buildozer.

## Принципы работы

- Данные хранятся локально, поэтому приложение работает автономно.
- Основной объект учёта — животное, к которому привязываются записи о здоровье, задачи и репродукция.
- Модели данных и бизнес-логика разделены по слоям: `models.py` и `controllers.py`.
- Интерфейс поддерживает русский и кыргызский варианты текста.

## Возможные сценарии использования

- ведение реестра молодняка и взрослых овец;
- контроль прививок и ветеринарных вмешательств;
- отслеживание сроков повторной обработки от паразитов;
- планирование осеменения и ожидаемого ягнения;
- оценка состава стада по полу и статусам.
